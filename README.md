# MULK — брокерская платформа недвижимости

> **Недвижимость, которую не просто размещают — её продают.**

Не «ещё одна доска объявлений», а **премиальный брокерский маркетплейс** с
AI-анализом каждого объекта, проверенными брокерами и медийной подачей.
Позиционирование — «следующий уровень» массовых площадок: меньше хаоса,
больше доверия, лучше визуал, AI-аналитика и живой брокер за каждым объектом.

Аудитория — Бишкек и Кыргызстан. Интерфейс на русском языке.

## Ключевые отличия (заложены в продукт)

| Блок | Что это |
|------|---------|
| 🧠 **AI-анализ объекта** | AI Property Score по 7 критериям, «Что можно построить на участке?», «Сравнить объекты», чат «Найди мне объект» словами |
| 🏆 **Премиум-витрина** | Отдельный раздел Prime / Elite — статусные объекты «как инвесткейс» |

| 👔 **Брокеры** | Профессиональные брокеры как лица проекта + кабинет-CRM |
| ✅ **«Проверено»** | Прозрачная проверка: документы, красная книга, собственник, цена к рынку |
| 💼 **«Продать объект»** | Тарифы упаковки (Стандарт / Pro / Premium / Elite) и кабинет продавца |
| 🏠 **Карточка объекта** | Мини-лендинг: причины купить, AI-анализ, сценарий жизни, инвест-потенциал, риски, похожие объекты, брокер |

## Технологии

- **Next.js 15** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS** — собственная дизайн-система (токены `ink / gold / emerald`)
- Без внешних UI-библиотек и без бинарных ассетов: иконки — inline-SVG,
  «фотографии» объектов — премиальные детерминированные градиент-плейсхолдеры
  (не зависят от сети, выглядят намеренно-дорого).

## AI: два режима

AI-функции работают **с ключом и без него**:

- **Живой режим** — если задан `ANTHROPIC_API_KEY`, запросы идут в Claude API
  (`/api/find`, `/api/compare`).
- **Оффлайн-режим** (по умолчанию) — встроенные детерминированные генераторы
  на основе данных объектов. Демо и все AI-функции работают всегда.

```bash
cp .env.example .env.local   # и впишите ANTHROPIC_API_KEY, чтобы включить живой режим
```

> ⚠️ AI-анализ — **не** юридическое заключение. Документы, назначение земли и
> кадастровые данные проверяются брокером и юристом отдельно.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
# продакшн:
npm run build && npm run start
npm run typecheck  # проверка типов
```

## Структура

```
app/
  page.tsx              Главная (витрина)
  catalog/              Каталог с клиентскими фильтрами
  property/[slug]/      Карточка объекта — «стар-страница» с AI-анализом
  premium/              Витрина Prime / Elite
  abroad/[slug]/        Зарубежные инвестнаправления
  brokers/[slug]/       Брокеры и профили
  sell/                 «Продать объект» + тарифы
  ai/                   AI-хаб (подбор, сравнение, «что построить», Property Score)
  verified/             Как мы проверяем объекты (доверие)
  dashboard/            Кабинеты продавца и брокера (демо)
  api/{find,compare}/   AI-эндпойнты (живой режим + фолбэк)
components/             Дизайн-система и переиспользуемые блоки
lib/
  data/                 Кураторские seed-данные (объекты, брокеры, районы, зарубежье)
  types.ts  utils.ts  ai.ts  site.ts
```

## Переименование бренда

Название и контакты вынесены в один файл — **`lib/site.ts`**. Поменяйте значения
там, и весь интерфейс подхватит их автоматически.
